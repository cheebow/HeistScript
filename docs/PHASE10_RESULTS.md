# Phase 10 結果: HSL・エディタ・初心者向け学習体験（2026-10-27）

## 実装した内容

| 項目 | 内容 |
|---|---|
| ホバーヘルプ | エディタで命令・条件・ID・キーワードにマウスを乗せると、書き方・意味・所要 tick・例（命令）、意味（条件）、日本語名・位置・説明・使い方（ID）を表示 |
| エラーの修正ガイド | 未定義 ID に「もしかして: jewel」（編集距離による候補）。end 忘れ・不明な命令・余分な記述・未解禁命令のメッセージに直し方を追記。実行時エラー（経路なし・隣接していない steal・隠れ場所でない hide・背後でない knockout・進路ふさがれ・命令数超過）に「対処:」を追記 |
| 整形 | 「整形」ボタンでブロックの深さに応じた 2 スペースのインデント（パース結果は不変） |
| 条件の可視化 | 状態パネルに、待機中の条件式とその評価結果（各述語の真偽）、主要 6 述語の現在値 |
| なぜ動かないか | 「いま: …」と理由（合図をまだ誰も送っていない／条件が成立していない: … が false／進路がふさがれている／スクリプト終了: move exit が足りない・未取得の宝物／エラーで停止: 原因と対処／次の tick にハンドラ開始） |
| 学習コンテンツ | ステージ定義に `learn`（学ぶ命令）/`goal`/`firstStep` を追加し、ヒントパネル上部に「学ぶ命令・ゴール・最初の一歩」を表示。6 ステージすべてに記入 |

HSL の構文・命令・イベントは変更していない。命令リファレンス（ヘルプ・補完・ホバー）は `COMMAND_DOCS` / `PREDICATE_DOCS` を単一の情報源とし、パーサが受理する構文のみを掲載。
