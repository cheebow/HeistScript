# Phase 12 結果: ゲームとしての仕上げ・リリース準備（2026-10-27）

## 実装した内容

| 項目 | 内容 |
|---|---|
| 画面構成 | タイトル画面（はじめる／つづきから／クレジット）→ ステージ選択（番号・題・学ぶ命令・クリア済み・最良 tick・チャレンジ★、カスタムは C）→ 作戦ブリーフィング（題・状況・ゴール・学ぶ命令・怪盗団・警備の構成・最初の一歩）→ ゲーム画面。ヘッダのロゴでステージ選択へ戻る。「ブリーフィング」ボタンで再表示。結果画面の「次のステージへ」は次のブリーフィングを開く |
| 深いリンク | `#play` でタイトルを飛ばす、`#stage=ID` でそのステージを直接開く（E2E・共有用） |
| 音 | 効果音・BGM を WebAudio で実装したが、プレイテストで「思考するゲームなので音は気が散る」との判断により完全に削除（2026-10-27）。設定からも除去 |
| キーボード | Space 実行/一時停止、N 1コマ進める、R 最初に戻す、Esc ダイアログを閉じる。エディタ・入力欄にフォーカスがあるときは無効 |
| 配布 | `vite build` のチャンク分割（phaser 1.2MB / monaco 3.9MB / react 0.2MB / app 0.17MB）、本番のみ登録するサービスワーカー（初回ロード後はオフラインで起動可）、LICENSE（MIT）、README にトラブルシューティング・ビルド・配布手順 |
| 品質 | 初回起動 → タイトル → Stage 1 ブリーフィングまでを E2E で確認。セーブ互換: `volume` を追加（欠けていれば既定値） |
