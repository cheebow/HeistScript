# Phase 10 計画: HSL・エディタ・初心者向け学習体験

## 変更対象

| 項目 | 内容 | ファイル |
|---|---|---|
| ホバーヘルプ | エディタで命令・条件・ID にマウスを乗せると説明・引数・例を表示 | `src/ui/monaco/setup.ts` |
| エラーの修正ガイド | 未定義 ID に「もしかして」候補（編集距離）。実行時エラーに「対処」文を追加 | `src/core/hsl/analyzer.ts`, `src/core/sim/vm.ts`, `thiefActions.ts` |
| 整形 | ブロックの深さに応じたインデント整形ボタン（2スペース） | `src/ui/format.ts`, `App.tsx` |
| 条件の可視化 | 状態パネルに選択中の怪盗の各述語の現在値と、待機中の条件式とその評価結果 | `src/core/hsl/ast.ts`（式→文字列）, `panels.tsx` |
| なぜ動かないか | VM の状態から日本語で説明（待機中／条件不成立／合図待ち／進路がふさがれている／ハンドラ実行中／スクリプト終了／エラー） | `src/ui/explain.ts`, `panels.tsx` |
| 学習コンテンツ | ステージ定義に `learn`（学ぶ命令）/`goal`/`firstStep` を追加し、ヒントパネル上部に表示 | `stages/*.json`, `src/core/model/stage.ts`, `panels.tsx` |

HSL の構文・命令・イベントは変更しない。

## 受け入れテスト

- ユニット: 整形、式の文字列化、「もしかして」候補、説明文の生成（待機・合図待ち・条件不成立・終了・エラー）。
- 既存: 6 ステージのサンプル解答が成功（stages.test）。
- E2E: 意図的な構文エラー／実行時エラーが日本語で表示され、修正→再実行→成功までが UI で完結する。整形ボタン。状態パネルの説明文。
