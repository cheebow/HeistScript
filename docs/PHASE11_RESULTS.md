### やり込み（11.2）

- クリア時に最速記録（tick・命令数・発見・気絶・警報・達成チャレンジ・そのときのスクリプト）とチャレンジごとの達成スクリプトを保存。
- ステージヘッダに記録バッジ（ホバーで内訳）とチャレンジの★、「ベストのコードを読み込む」ボタン。結果画面ではクリア条件とチャレンジを分けて表示（既存）。

### ステージエディタ（11.3、先行サブフェーズ）

- 「ステージの読込/書出」ダイアログ: JSON ファイルの読み込み（検証エラーを一覧表示、組み込み ID との重複を拒否）、現在のステージの書き出し（ダウンロード）、カスタムステージの削除。読み込んだステージは localStorage に保存され、一覧の末尾に「（カスタム）」として追加される。
- GUI での地形・オブジェクト編集は後続サブフェーズ（未実装）。
